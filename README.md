# Book Search 
- Uses Open Library Search API

## Stack

Frontend
- TypeScript
- React
- Vite

Backend
- Typescript
- Node
- Express
- SQLite (better-sqlite3)

## Requirements

- Node 22.12 or greater
- npm

## Setup
1. Install both npm projects
    - `npm run install:all`

### Development
2. Run server
    - `cd server`
    - `npm run dev`

3. Run client
    - `cd client`
    - `npm run dev`

### Production
2. Build
    - `npm run build`

3. Run
    - `npm start`

Open http://localhost:3000 in browser

## Database

Database file and table are created on the first server boot
